# ארצות ודגלים

משחק ילדים בעברית ובאנגלית: מנחשים איזו מדינה מהבהבת על המפה, מזהים דגלים, ויוצאים לחפש אוצר באונייה.

## משחקים

- **ניחוש** – מדינה מהבהבת על המפה ובוחרים את שמה מבין שלוש אפשרויות.
- **הפוך** – מקבלים שם של מדינה ולוחצים עליה במפה.
- **דגלים** – מזהים את הדגל של המדינה.
- **חיפוש אוצר** – לוחצים על האונייה במפה העולמית. אוצר מוסתר באחת המדינות, וכל ניחוש שגוי מפליג לשם ומחזיר "חם/קר", כיוון ורמז חדש. חמישה אוצרות בכל סיבוב. משחק האונייה אינו מושפע ממצב האתגר.

מצב אתגר (🔥) משפיע על משחקי החידון בלבד.

## הרצה

אין צורך בבנייה, בתלויות או בקבצים נוספים. אפשר לפתוח את `index.html` ישירות בדפדפן, או להפעיל שרת מקומי:

```bash
python3 -m http.server 8000
# ואז לפתוח http://localhost:8000
```

## פרסום ב-GitHub Pages

1. מעלים את `index.html` (ואת `.nojekyll`) למאגר.
2. ב-Settings ← Pages בוחרים את הענף `main` והתיקייה `/ (root)`.

## מבנה

```
index.html   המשחק כולו בקובץ אחד: קוד, מפה, תרגומים ו-167 דגלי SVG
```

## הערות

- באייפד: צביטה משנה רק את זום המפה, ולא את גודל הדף כולו.
- הדגלים מוטמעים בתוך `index.html` (גודל הקובץ כ-2.5MB), והם מבוססים על ספריית flag-icons (MIT).
